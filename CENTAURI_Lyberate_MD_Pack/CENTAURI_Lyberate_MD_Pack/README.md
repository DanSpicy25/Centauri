# CENTAURI / LYBERATE — Paquete maestro de documentación

Este paquete establece el contrato de trabajo para construir desde cero la nueva presencia digital de **Lyberate** y, de forma progresiva, su centro administrativo privado.

## Cómo usarlo

1. Descomprime el ZIP en una carpeta de trabajo nueva.
2. Abre esa carpeta en tu agente de programación (Antigravity, Cursor u otro).
3. Empieza únicamente con `phases/PHASE_00_AUDIT.md`.
4. En cada fase, abre una conversación nueva y adjunta/indica:
   - `CENTAURI_MASTER.md`
   - `PHASES.md`
   - el documento de la fase actual
   - `PHASE_REPORT_TEMPLATE.md` y el informe de la fase anterior, cuando exista.
5. No pidas que implemente todas las fases de golpe. Cada fase debe acabar con un informe y pruebas verificables.
6. Mantén las aplicaciones existentes como referencias independientes. El proyecto nuevo se construye desde cero; no reescribas repositorios antiguos durante la auditoría.

## Principio de producto

La primera entrega debe ser una **web pública excepcional de Lyberate**, con un landing page visualmente memorable, el carrusel/vitrina de proyectos integrado en Inicio, páginas de Sobre nosotros y Trabajos/Portafolio, Servicios, Productos y Contacto. El panel administrativo será una aplicación privada y separada, con su propia arquitectura, navegación y sistema de permisos.

La experiencia debe parecer diseñada por un equipo de producto con criterio, no una plantilla SaaS generada automáticamente.
