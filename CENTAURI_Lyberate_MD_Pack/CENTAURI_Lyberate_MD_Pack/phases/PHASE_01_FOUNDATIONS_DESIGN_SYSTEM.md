# FASE 01 — Fundaciones frontend y sistema visual

## Leer
`CENTAURI_MASTER.md`, `PHASES.md`, `DESIGN.md`, `ARCHITECTURE.md`, `API.md`, el último `PHASE_REPORT.md`.

## Objetivo
Crear la base frontend nueva y el sistema visual Lyberate aprobado en Fase 00. No implementar todas las páginas ni módulos futuros.

## Tareas
- Crear estructura mantenible y scripts de desarrollo/build/lint/test apropiados para la stack aprobada.
- Separar rutas/layouts públicos y administrativos, aunque el panel completo se construya más adelante.
- Implementar tokens, tipografía, paleta, espaciado, radios, foco, elevación y movimiento.
- Crear componentes base accesibles: botones, enlaces, campos, badges, alertas, diálogo, tabs, breadcrumb, skeleton, empty/error states, cabecera y footer.
- Definir layout responsive, navegación móvil y utilidades de composición.
- Configurar lint, TypeScript estricto si la stack lo permite y pruebas mínimas.
- Añadir fixtures explícitos para desarrollo, separados de API real.
- Documentar cómo arrancar, probar y compilar.
- Probar teclado, focus, contraste, reduced motion y al menos tres tamaños de viewport.

## No hacer
- No crear un dashboard de métricas falso.
- No implementar CRM, finanzas ni conectores.
- No introducir librerías visuales pesadas sin justificar.
- No copiar componentes viejos sin inspección y aprobación.

## Aceptación
Build limpio; sistema visual documentado; componentes demostrables; rutas/layouts base separados; sin secretos; responsive y accesible; informe de fase.
