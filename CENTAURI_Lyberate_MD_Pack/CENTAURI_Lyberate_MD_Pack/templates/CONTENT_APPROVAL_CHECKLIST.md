# Lista de aprobación de contenido público

- [ ] Nombre, descripción y estado verificados.
- [ ] Relación de Lyberate con el proyecto descrita con honestidad.
- [ ] Permiso para usar marca, capturas y logotipos confirmado.
- [ ] No aparecen datos personales/confidenciales.
- [ ] Funciones y tecnologías verificadas.
- [ ] No se inventan métricas, testimonios, premios ni resultados.
- [ ] Imágenes con texto alternativo y crédito cuando corresponda.
- [ ] Enlaces revisados.
- [ ] Vista móvil y escritorio revisadas.
- [ ] SEO básico revisado.
- [ ] Aprobación humana registrada.
